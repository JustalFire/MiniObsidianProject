Этот проект называется Mini Obsidian и представляет собой веб-приложение совмещенное с Telegram-ботом для создания заметок на бесконечном холсте и построения связей между ними. Бэкенд написан на Java 17 с использованием Spring Boot 3, а фронтенд сделан на HTML, CSS и JavaScript. Все данные хранятся прямо в текстовых файлах в папке data.

В проекте есть Telegram-бот, который работает через Long Polling. С его помощью можно управлять заметками прямо из чата, используя стандартные команды для добавления заметок, создания связей, удаления или просмотра списков. Главная его фишка это кнопка открытия Mini App, которая прямо в телеграме открывает интерактивный холст.

Веб-интерфейс работает как бесконечный холст. Карточки с заметками можно свободно перетаскивать мышкой, при этом все линии связей перерисовываются автоматически, а координаты сразу сохраняются на сервере. По клику открывается полное содержимое заметки, а по клику правой кнопкой мыши вызывается контекстное меню для создания новых заметок, их редактирования, удаления или включения режима соединения, когда кликом по второй карточке между ними прокладывается линия.

Для запуска проекта потребуется установленная Java 17 и среда разработки IntelliJ IDEA. Сначала нужно создать бота через BotFather в телеграме, получить токен и прописать его в файл конфигурации local.properties. Так как для WebApp в телеграме обязательно нужен защищенный протокол https, в проекте используется утилита cloudflared, которая создает туннель для локального порта 8080, а полученный адрес тоже прописывается в конфигурацию. После этого можно запускать главный класс приложения ObsidianApplication и открывать бота либо сайт в браузере
